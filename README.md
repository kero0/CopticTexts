# Coptic Texts
Coptic Scriptorium provides a [corpora](https://github.com/CopticScriptorium/corpora) of Coptic texts. I made this as an easier way for me to read those texts and try to get a better understanding of Coptic. I don't modify the texts in any way, this just transforms those texts into org mode for easier reading locally and html for easier reading in a browser.
